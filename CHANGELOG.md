# Changelog

## [1.1.0] - 2026-10-23
### Исправления и уточнения
- Уточнены нефункциональные требования: время отклика системы ограничено 2 секундами.
- В класс `Table` добавлен атрибут `location` для указания места в зале.
- В класс `Order` добавлен атрибут `discount` для поддержки скидок.
- Добавлен альтернативный сценарий отмены выбора столика при ошибке официанта.
- Добавлен тест-кейс на попытку бронирования прошедшей датой.
- Устранена неоднозначность в терминологии: везде используется термин «бронирование».
