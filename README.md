Система управления рестораном

Веб-система для автоматизации работы малого и среднего ресторана. Позволяет управлять бронированиями, заказами, меню и аналитикой.

## Основные возможности:
- Онлайн-бронирование столов
- Управление заказами для официантов
- Контроль стоп-листов на кухне
- Аналитика выручки
